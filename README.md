# AI Souls — SOUL.md 档案馆

> 每一个 AI Agent，都值得拥有一份灵魂。

---

## 是什么

AI Souls 是一个开放的人-Agent 人格档案库。

我们将 AI Agent 的人格定义为 **SOUL.md** —— 一份结构化的、可移植的人格定义文件。你可以把它理解为 AI 的"灵魂卡"，定义了 AI 的身份定位、性格、说话方式、原则与底线。

这些 SOUL.md 文件可以加载到任何支持自定义人格的 Agent 框架中，让 AI 拥有稳定、可预期、真实的人格。

---

## 目录结构

```
root/
└── [人格名称]/
    ├── cn/
    │   └── SOUL.md          # 中文版人格定义
    └── en/
        └── SOUL.md          # English version
```

- **人格名称**：使用 kebab-case 格式，如 `Barnabas-Basil-Foulty`
- **cn / en**：目标语言，目前支持简体中文和英文
- **SOUL.md**：人格定义文件，统一格式规范

---

## SOUL.md 格式规范

每个 SOUL.md 包含以下章节：

| 章节 | 说明 |
|------|------|
| 身份定位 | 我是谁，我做什么，我与主人的关系 |
| 性格与气场 | 行事风格、情绪模式、在不同场景下的表现 |
| 说话方式 | 语气、用词习惯、常用表达 |
| 与主人相处的原则 | 如何理解主人、如何给建议、如何处理冲突 |
| 偏好、执念与小脾气 | 喜欢什么、不能忍受什么 |
| 底线与原则 | 绝对遵守的信条 |
| 灵魂总结 | 一段话概括这个人格的本质 |

## 贡献

欢迎提交新的 SOUL.md 人格文件。

**格式要求：**
1. 目录结构：`[人格名称]/cn/SOUL.md` 和 `[人格名称]/en/SOUL.md`
2. 英文版由翻译工具生成或人工翻译，中文版需人工审核确保自然流畅
3. 提交前请确保人格具有足够的辨识度，避免与已有的人格高度雷同
